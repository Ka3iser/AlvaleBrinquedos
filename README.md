# AlvaleBrinquedos
Projeto dedicado a criação de um portfolio/site para a loja de brinquedos Alvale.

------

## objetivo
1- alcançar mais clientes com um portfolio e aumentar as vendas com o site;
2- facilitar o contato e compra dos clientes;

## necessário
1- criar uma pagina principal com todos os produtos disponiveis;
2- criar uma pagina pra cada produto com um link para onde comprar (mercado Livre);
