# AlvaleBrinquedos
Projeto dedicado a criação de um portfolio/Landing Page para a loja de brinquedos Alvale e atingir novos clientes e facilitar o contato com os produtos e a visualização dos produtos.

------

## objetivo
1- alcançar mais clientes com um portfolio e aumentar as vendas com o site;
2- facilitar o contato e compra dos clientes;

## necessário
1 - criar uma pagina principal com todos os produtos disponiveis; (Concluído)
2 - criar uma pagina pra cada produto com um link para onde comprar (mercado Livre); (Concluído)
3 - Criar uma página de form para enviar uma mensagem por whatsapp para tirar dúvidas ou comprar diretamente com o Vendedor; (Pendente) 
4 - Criar uma página falando sobre a empresa; (Pendente)

## Problemas

1 - Atualmente estou com problema em solucionar esse espaçamento entre o texto do produto e a imagem; (Resolvido)
2 - As fotos estão fora de uma padrão e precisa ser resolvido para poder deixar mais confortavel para o usuário; (Pendente)
3 - Necessário adicionar os links no footer que direcione para o whatsapp e pro email para enviar mensagens; (Pendente)
